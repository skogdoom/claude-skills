# Claude Skills

This repository contains Claude Skills.

- [`shelf-catalog`](./shelf-catalog/SKILL.md): Transcribes book, comic, or media spines from a photo of a shelf into a structured list, delivered as a spreadsheet.
- [`mutation-check`](./mutation-check/SKILL.md): Verify that a test would actually fail if the thing it guards broke, by deliberately breaking that thing and watching.
